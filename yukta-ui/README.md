# Yukta UI

A web-based dashboard for monitoring Yukta workflows, sessions, and logs.

## 🏗️ Architecture

- **Backend**: JTE (Java Templating Engine) for server-side rendering.
- **Frontend**: Tailwind CSS, Alpine.js, and D3.js/ELK for graph visualization.

## 🚀 Features

- **Workflow Visualization**: Interactive DAG rendering of current workflows.
- **Live Logs**: Real-time viewing of task outputs.
- **Session Overview**: List of active and historical sessions.

## 🛠️ Tech Stack

- **JTE**: Fast, type-safe templates.
- **Alpine.js**: Lightweight frontend interactivity.
- **Tailwind CSS**: Utility-first styling.
