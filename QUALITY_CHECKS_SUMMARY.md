# Quality Checks Configuration Summary

## Overview
All quality checks are now configured to run as part of `./gradlew check` across **all modules** for both **main and test source code**.

## Checks Included in `gradle check`

### ✅ 1. Spotless Code Formatting
- **Scope**: Java files, Kotlin Gradle files, XML files
- **Main & Test**: ✅ Yes
- **All Modules**: ✅ Yes
- **Config**: `config/license/` (header), `spotless` plugin configuration
- **Details**: Enforces Google Java Style Guide, license headers, import ordering

### ✅ 2. Checkstyle (Main + Test)
- **Scope**: Java source code style violations
- **Main & Test**: ✅ Yes (enabled for both)
- **All Modules**: ✅ Yes
- **Config**: `config/checkstyle/checkstyle.xml`
- **Task Names**: `checkstyleMain`, `checkstyleTest`

### ✅ 3. PMD (Main + Test)
- **Scope**: Java code quality issues
- **Main & Test**: ✅ Yes (enabled for both)
- **All Modules**: ✅ Yes
- **Config**: `config/pmd/ruleset.xml`
- **Task Names**: `pmdMain`, `pmdTest`

### ✅ 4. SpotBugs (Main + Test)
- **Scope**: Potential bugs in compiled Java code
- **Main & Test**: ✅ Yes (enabled for both)
- **All Modules**: ✅ Yes
- **Config**: `config/spotbugs/exclude.xml`
- **Exclusions**:
  - CLI module (`com.infenia.yukta.cli.*`)
  - JTE generated code (`gg.jte.generated.**`)

### ✅ 5. Semgrep Static Analysis
- **Scope**: Security and code quality patterns (Java)
- **Main & Test**: ✅ Main only (as per design)
- **All Modules**: ✅ Yes (applies to all with `src/main/java`)
- **Config**: `config/semgrep/.semgrep.yml`
- **Rulesets**: 
  - p/security-audit
  - p/java
- **Environment**: Uses temporary HOME directory to avoid filesystem permission issues

### ✅ 6. Unit Tests (JUnit 5)
- **Scope**: Java tests with Reactor testing support
- **Coverage**: All `*Test.java` files
- **All Modules**: ✅ Yes
- **Config**: `useJUnitPlatform()` in java-conventions

### ✅ 7. JaCoCo Code Coverage
- **Scope**: Code coverage verification
- **Main & Test**: ✅ Yes
- **All Modules**: ✅ Yes
- **Config**: `build-logic/src/main/kotlin/com.infenia.yukta.jacoco-conventions.gradle.kts`
- **Thresholds**:
  - Default: 100% for LINE, BRANCH, CLASS, INSTRUCTION, METHOD
  - Exceptions configured in module `build.gradle.kts` via `coverageConfig`
  - Minimum floor: 80% for exceptional classes

## Module-Specific Notes

### build-logic
- Applies convention plugins; quality checks run on Kotlin Gradle files

### boot, core, web, ui, mcp, messaging, plugin-api
- All inherit quality checks through `spring-conventions`
- Full coverage requirements apply

### cli
- Inherits quality checks through `quality-conventions`
- SpotBugs excludes entire CLI module (`com.infenia.yukta.cli.*`)
- PMD and Checkstyle run on both main and test code

### ui
- JTE-generated code excluded from SpotBugs (`gg.jte.generated.**`)
- Coverage exceptions for UI code (`com.infenia.yukta.ui.*`)
- All quality checks apply to source code

### plugins/* (processors, terminals, triggers, internal)
- All inherit quality checks through build-logic conventions
- Standard coverage requirements apply

## Running Quality Checks

```bash
# Run all quality checks
./gradlew check

# Run specific quality checks
./gradlew spotlessCheck          # Format checking only
./gradlew checkstyleMain         # Checkstyle on main code
./gradlew checkstyleTest         # Checkstyle on test code
./gradlew pmdMain                # PMD on main code
./gradlew pmdTest                # PMD on test code
./gradlew spotbugsMain           # SpotBugs on main code
./gradlew spotbugsTest           # SpotBugs on test code
./gradlew semgrep                # Semgrep on main code
./gradlew test                   # JUnit tests
./gradlew jacocoTestCoverageVerification  # Coverage verification

# Fix formatting automatically
./gradlew spotlessApply
```

## AOT-Generated Code Exclusion

Quality checks are disabled for AOT-generated code (Spring Boot native compilation):
- `checkstyleAot*` tasks disabled
- `pmdAot*` tasks disabled
- `spotbugsAot*` tasks disabled

This prevents quality checks from running on generated bytecode that is beyond developer control.

## Implementation Details

### Key Changes Made

1. **quality-conventions.gradle.kts**
   - Removed module-specific exceptions for CLI and UI
   - Removed test sourceset exclusions from Checkstyle, PMD, and SpotBugs
   - Kept only AOT exclusion (generated code)
   - Added semgrep to `check` task
   - Fixed semgrep environment to use temporary HOME directory

2. **spotbugs/exclude.xml**
   - Added JTE generated code exclusion (`gg.jte.generated.**`)
   - Kept CLI exclusion

3. **semgrep/.semgrep.yml**
   - Fixed invalid rule configuration
   - Uses recommended registry rulesets (security-audit, java)

4. **cli/build.gradle.kts**
   - Removed all coverage exceptions (100% coverage required)

  ├── pmdMain
  ├── pmdTest
  ├── spotbugsMain

## Notes

- All checks are applied consistently across all modules
- No module has special treatment except for generated/AOT code
- Test code is subject to the same quality standards as main code
- Coverage requirements are enforced globally with per-module exceptions
- Semgrep requires temporary HOME directory to avoid read-only filesystem issues
